Projects

Robot Bakery

A Codex-orchestrated development platform that turns Jira tickets into a repeatable engineering workflow. All engineers use it; I continue to maintain and extend it.

Technical notes

My contribution

I developed Robot Bakery using Codex to orchestrate a standard software development lifecycle. Engineers start work with bakery process [jira ticket id]; the orchestrator drives the ticket through discovery, design, planning, implementation, testing, review, and closure.

A workflow with explicit gates

  1. Discovery
  2. Design
  3. PlanningHuman approval before implementation
  4. ImplementationTest-driven development
  5. TestingUnit, integration, and browser tests
  6. Review
  7. Closure

Each step pairs a task-tuned delegated agent with a read-only critic. The primary orchestrator uses codified scripts to enforce workflow state and sends work through further iterations until both agents agree on completion. Agent agreement does not replace human approval: operators approve plans before implementation and remain responsible for pull-request approval, merging, and deployment.

Pantry MCP: context that survives a session

I built Pantry, a local Model Context Protocol (MCP) service and CLI backed by SQLite. It preserves facts, decisions, procedures, and lessons across sessions, tickets, and repositories. Scoped, provenance-aware recall lets agents retrieve relevant context without loading the full history; its search uses local text similarity.

Pantry holds compact operational lessons. Repository-based knowledge files hold detailed, reviewable material about missteps and preferred patterns, shared across developers. Memory entries require accurate scope and provenance and exclude secrets.

AI Support Skills

Operator-invoked Codex skills for investigating AWS alarms and reconstructing a Vivian user's experience from system records and conversations.

Technical notes

My contribution

I developed two investigation skills that connect operational evidence to an engineer's next decision. A human operator starts each skill in a Codex prompt; the skills use read-only queries and produce reports.

Alarm investigation and root-cause analysis

The operator supplies the CloudWatch alarm contents. The skill queries Lambda logs to locate the error, follows the evidence through CloudWatch Logs Insights and DynamoDB, and examines the repository code that generated the log entry to trace the failure.

The RCA report includes the queries and supporting facts, the most likely cause, and a recommended fix. Investigations can reveal code defects, property misconfigurations, or suspected security attacks. The output is evidence and a recommendation for the engineer, not an automatic production change.

A user's full audit trail

The operator supplies an identifier such as an email, phone number, name, or web-chat ID. The skill first finds the user profile, then follows persisted profile states, transactions, and conversation turns through DynamoDB records and CloudWatch logs.

The resulting report contains a detailed timeline of system events and the complete conversation between Vivian and the user, bringing the relevant records together for review.
